# Örnekler

- `output/`: Yerelde saklanan eski MP4, SRT ve önizleme çıktıları. Üretim çıktısı olduğu için Git tarafından dışlanır; yeni klonlarda bulunmaz.
- `projects/`: Bu üretimlerden kalan proje manifestleri. Kişisel/üretilmiş anlatım dosyaları burada bulunmaz; manifestler tam bir yeniden render paketi değildir.

Yeni üretimler depo kökündeki `output/` ve `projects/` klasörlerine yazılır. Örnek dosyalar otomatik üretim sırasında değiştirilmez.

Tam yerel render testleri sentetik medya oluşturur. B1 için ek örnek manifest ve anlatım, `skills/directing-stickman-videos/examples/b1/` altında bulunur.
